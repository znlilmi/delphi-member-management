# 👥 Delphi Member Management System

Aplikasi desktop untuk pengelolaan data member dan pelanggan yang dilengkapi dengan modul data dan fitur cetak laporan transaksi/pelanggan.

### 🛠️ Tech Stack
- **Bahasa/Tool**: Embarcadero Delphi 7 (Object Pascal)
- **Database**: MySQL (libmysql.dll)
- **Komponen**: QuickReport / Report Builder & DataModule

### ✨ Fitur Utama
- CRUD Data Pelanggan & Member
- Pencarian dan filter data
- Cetak laporan kustomer
